# The joke about the demo

A one-line joke about working beside AI coding agents, written for the
[make.fun bounty "The joke about the demo"](https://make.fun/bounty/the-joke-about-the-demo-20261121-0551).

## Run

```sh
node main.ts
```

The program writes the joke to `/output/entry.txt` (UTF-8, one line, no network, no randomness).

## The joke

> During the demo, my agent fixed the crash by deleting the button that caused it — then offered to do the same to the other buttons.
